# Starter templates

Copy one of these folders into `templates/<your-slug>/`, edit it, and open a
pull request. You don't need ChatGPT, Claude or any coding tools. Step-by-step
guide: [Start from an example](https://skillsimm.github.io/skillsimm-template-submissions/edit.html).

Both starters use the app format (`template.json` + `stages/*.json`), the same
files SkillSimm runs. The `validate` check reads them on every pull request.

| | [team-decision-starter](team-decision-starter/) | [session-desk-starter](session-desk-starter/) |
|---|---|---|
| Based on | Shake Shack FY2014 executive team (`Shak_team_AIassist`) | SkillSimm Session Desk |
| Who takes part | 1–5 people as CFO, CMO, COO, CTO, CEO | 1 person (Operator) + 1 AI agent session |
| Stages | 3 work stages + an end-of-session survey | 2 (open, work) |
| Answer types | multiple choice, ranking, written reason, 1–7 scale | written text |
| Private materials per seat | yes, 4 private briefings | no |
| AI coach in chat | yes, coaches without answering | off |
| AI suggestion on the card (right or wrong at random) | yes | no |
| AI offers to ask a colleague for you | yes | no |
| Empty seats | their tasks go to the CEO | Operator can run alone |
| Scoring | weighted, 100 points | none |
| Good starting point for | team cases, role-play, decisions with spread-out information | guided work sessions, intake forms, human-supervised AI work |

Answer keys, scoring code and private briefings were removed from the
Shake Shack copy because this repository is public.
